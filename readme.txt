Add a responsive sliding SideMenu to your WordPress site with a block.

== Description ==

SideMenu Block adds an off-canvas panel that slides in from the side of your site and can be opened from a block button placed in your content, templates or template parts.

The block uses a normal published page as the SideMenu panel content. Create a page with the blocks you want to show in the panel, then add the "SideMenu Open Button" block wherever visitors should be able to open it.

= Key features =

* SideMenu Open Button block for posts, pages, templates and template parts.
* Uses normal WordPress pages for SideMenu panel content.
* Default SideMenu page selector in the block editor.
* Button text and hamburger icon controls.
* Block styling support for color, typography, spacing, dimensions and borders.
* Responsive sliding panel with cover overlay and close button.

= How to use the SideMenu block =

1. Create and publish a page containing the blocks you want to show in the sliding panel.
2. Add the "SideMenu Open Button" block to a post, page, template or template part.
3. Set the button text and choose whether to show a hamburger icon.
4. Choose the default SideMenu page from the block settings.

The block uses one default SideMenu page.

== Installation ==

1. Install "SideMenu Block" automatically from the WordPress plugin directory, or upload the plugin ZIP file.
2. Activate the plugin from the "Plugins" screen in WordPress.
3. Create a published page for your panel content and place the "SideMenu Open Button" block where you want the button.

== Frequently Asked Questions ==

= Where is the SideMenu content managed? =

SideMenu Block uses normal WordPress pages. Create or edit the page that should appear inside the sliding panel.

= Can different buttons open different SideMenu pages? =

The block uses one default SideMenu page.
